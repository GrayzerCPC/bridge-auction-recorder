This project has been designed by ChatGP{T (!) to enable Duplicate Bridge bid tracking so that the player(s) can analyse their bidding and suibsequect play after a day's session.
We needed to do it this way as a result of the Bridge Club changing from hand-written bidding sheets to bidding boxes which don't allow easy bid recording. The obvious solution is by camera photogrsphy but that's been found - for us - to be unsatisfactory.
Hence the Bridge Auction Recorder!
