This project has been designed to enable Duplicate Bridge bid tracking by individual players so that they (and their partners often) can analyse their bidding and subsequect play after a day's bridge session.
We needed to do it this way as a result of the Bridge Club changing from hand-written bidding sheets to bidding boxes which don't allow easy bid recording. The obvious solution is by camera photography but that's been found - for us - to be unsatisfactory.
Hence the Bridge Auction Recorder!
